# 纸本文物外借展陈 · 紫外光照剂量复核

静态站点：保管员在浏览器录入展柜与灯的参数，复核灯光联动是否会在任意连续时间窗口内
对纸张造成超剂量紫外照射。

## 功能

- 录入 **2–6 个展柜**：名称、滑动暴露窗口（分钟）、累计剂量上限（μW·min/cm²）；
- 录入 **3–8 盏灯**：灯号、左闭右开启停区间 `[启动, 停止)`、对每个展柜的紫外线照度（μW/cm²）；
- **复核**：
  - 将所有灯的启停区间叠加为**分段恒定照度**；
  - 在连续时间上**精确**求每个展柜指定长度滑动窗口的最大积分剂量（不使用固定采样点）；
  - 按展柜展示：完整时段累计剂量、最大窗口剂量及其**精确起止时刻**、窗口内照度变化、
    照度曲线图（最大窗口高亮）与完整时段照度分段；
  - 超限时给出**首项证据**：按展柜输入顺序取首个超限展柜，其违规窗口起点由
    “取得最大窗口剂量的最早起点”稳定确定；
- **校验**：非法区间、重复灯号、不合理限额、数量越界、非法数字等问题**一次全部列出**并阻止复核；
- **本地持久化**：草稿与最近一次有效复核结果保存在 `localStorage`，重新打开可继续调整；
  草稿一旦修改，旧结论立即失效并不再显示（重新打开时仅当草稿与复核时完全一致才展示旧结论）。

## 精确性说明

- 全部数值以 BigInt 有理数运算；输入为有限小数时，所有结果仍为有限小数并原样精确显示
  （如 `0.1 + 0.2 = 0.3` 严格成立）。
- 滑动窗口剂量 `W(t) = D(t+L) − D(t)` 是分段线性函数，其最大值只可能出现在
  `t = b` 或 `t = b − L`（`b` 为照度断点）处；引擎对全部候选点精确求值取最大，
  因此能发现起点位于断点之间的最大窗口（固定采样会漏掉）。
- 窗口起点限定在展陈时段内（`T0 ≤ t ≤ T1 − L`；窗口长于整个时段时取 `[T0, T0+L)`）。
  由于照度非负，该限制不改变最大剂量值，仅使报告的起止时刻更直观。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run test     # 逻辑校验（剂量引擎单元测试）
npm run build    # 生产构建到 dist/
```

## Docker 运行

```bash
# 启动静态站点（宿主机端口默认 8080，可用 WEB_PORT 配置）
WEB_PORT=8080 docker compose up --build web

# 浏览器访问
open http://localhost:8080
```

- `web` 服务：多阶段构建（Node 构建 → Nginx 托管 `dist/`），
  内置 `/healthz` 健康检查端点，Compose 中配置了健康检查与端口映射。

## 一次性校验服务 verify

`verify` 服务依次完成 **逻辑校验（单元测试）→ 生产构建 → 页面可访问检查**，
随后自行退出，并以退出码报告结果（`0` = 全部通过，非 `0` = 失败）：

```bash
docker compose run --build --rm verify
echo $?        # 0 表示通过

# 或
docker compose up verify --build --exit-code-from verify
```

## 目录结构

```
index.html            页面入口
src/engine.js         剂量引擎：精确有理数、区间叠加、滑动窗口最大积分、草稿校验
src/engine.test.js    引擎单元测试（逻辑校验）
src/main.js           页面交互、本地持久化、结论渲染
src/styles.css        样式
scripts/verify.sh     verify 服务入口：测试 → 构建 → 可访问检查
scripts/check-page.mjs 静态托管 dist/ 并检查首页与全部引用资源可访问
nginx/default.conf    Nginx 站点配置（含 /healthz）
Dockerfile            多阶段：base / verify / build / web
docker-compose.yml    web（端口可配 + 健康检查）与 verify（一次性）
```
